# Warehouse Inventory Analysis

## Project Overview

This project analyzes a fictional warehouse-club inventory dataset inspired by large membership retailers such as Sam's Club.

The goal was to organize inventory records, calculate inventory values, identify low-stock products, and create a dashboard to summarize inventory performance.

## Tools Used
- Google Sheets
- Microsoft Excel

## Project Features
- Organized inventory across seven retail departments.
- Calculated inventory values using spreadsheet formulas.
- Identified low-stock products automatically.
- Summarized inventory value by department.
- Created a dashboard with key performance indicators (KPIs).
- Visualized department inventory values using a column chart.

## Spreadsheet Skills Demonstrated
- SUM
- IF
- COUNTIF
- SUMIF
- Data organization
- Inventory analysis
- Basic dashboard creation

## Key Findings

- **Total Products:** 10
- **Total Inventory Value:** $4,044.50
- **Products Identified as Low Stock:** 5

## Project Files

- `warehouse_inventory_analysis.xlsx` — Completed inventory workbook containing inventory records, calculations, department summaries, and dashboard.

## Data Disclaimer

All product names, quantities, costs, and prices are fictional and were created for educational and portfolio purposes. No actual Sam's Club inventory or confidential business information was used.
